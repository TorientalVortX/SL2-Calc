# Tandem summoning — player confirmations

Date: 2026-09-15. Source: repository owner in the Redtail Shapeshifter / Grand Summoner build conversation. Confidence: strong (direct player report; not independently reproduced here). Live game patch unspecified.

- Two equipped Summoner's Tandem Daggers both trigger when a summon happens.
- Enflamed applies per hit, including each dagger's triggered hit.
- Each Youkai has a separate repeat-action counter. Summoning a different Youkai does not inherit the previous Youkai's repeat surcharge.
- Follow-up on 2026-09-16: damaging Youkai Evokes use 250% of the actual user's relevant elemental ATK. Do not substitute the contracted Youkai's stats or generic weapon SWA. Status-only Evokes such as Wink have no damage term. Special-case Evokes should retain any explicitly established exceptional behavior rather than silently conflating it with generic elemental damage.

Combine these with the documented once-per-weapon-per-round critical Momentum refund and conditional Ripple Dimension reduction. Do not assume a refund on every critical or that Chain Unsummon is free or clears repeat counters. Budget its 3M/10 FP at rank 3. Different first-time summons avoid each other's repeat FP surcharge; repeating the same identity remains subject to its counter.

Unresolved: minimum reduced Summon Momentum, enchantment-rider magnitude under attack modifiers, which materials qualify for Enflamed's Fire-material bonus, and weakness-refund source limits. These confirmations do not assert all summon-like skills use the same item triggers.
