# Historical reference notes

These files preserve the source notes used during the original calculator implementation. They are non-authoritative, may be incomplete or outdated, and are not shipped in the web application.

Update the validated JSON under `src/data/` instead. If a note conflicts with the calculator's tested behavior, verify it independently before changing a formula or record.

`mechanics/` holds research notes from August to October 2026: the Hit/Evade model, sourced mechanics, and the verification backlog. `status-effects-catalog.md` and `talents-catalog.md` are generated by `npm run build:statuses` and `npm run build:talents`.
